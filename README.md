# 📊 Descriptive Statistics & ML Fundamentals from Scratch (Python)

This repository contains custom Python implementations of core descriptive statistics tools without using pre-built library functions (like NumPy or SciPy) to deeply understand the underlying mathematical concepts.

## 🛠️ Implemented Functions
* **Central Tendency:** Mean, Median, Mode
* **Dispersion:** Standard Deviation, Quantiles
* **Shape/Moments:** Standardized Central Moments ($k$-th order)

## 📁 Dataset Used
* `bike_count.csv` - Used for testing custom algorithms against real-world data.

## 💡 Key Learnings
Understanding how statistical functions process data lists manually, handling even/odd length lists for medians, and computing mathematical moments directly in Python.
